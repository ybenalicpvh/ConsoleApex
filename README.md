# ConsoleApex

ConsoleApex enables real-time data processing and auto-scaling for distributed systems, streamlining operations on the console and Apex platform.

The key benefits of using ConsoleApex include:

- ConsoleApex enables real-time data processing
- and auto-scaling for distributed systems,
- streamlining operations on the console

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ConsoleApex.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ConsoleApex is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
